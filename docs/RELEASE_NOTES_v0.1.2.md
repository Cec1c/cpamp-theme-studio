# v0.1.2 — Native top-bar Theme control

## English

This release moves Theme Studio to the place CPAMP users already expect.

- Reuses the existing top-right Theme control and preserves CPAMP's native icon, spacing, hover state, and responsive layout.
- Replaces the native control's click behavior with Theme Studio while retaining automatic, light, and dark modes inside the editor.
- Removes the lower-right floating launcher completely.
- Keeps one accessible dialog trigger with `aria-haspopup` and synchronized `aria-expanded` state.
- Rebinds the host control after SPA navigation or a CPAMP DOM refresh.
- Retains saved palettes and all other browser-side preferences from v0.1.1.

Upgrade through the CPAMP Plugin Store to `0.1.2`, refresh the panel once, and use the existing Theme button in the top-right action row.

## 简体中文

此版本将主题工作室放到 CPAMP 用户原本就会寻找的位置。

- 复用右上角原有的“主题”控件，保留 CPAMP 原生图标、间距、hover 状态与响应式布局。
- 用主题工作室替换原控件的点击行为；编辑器内仍提供跟随系统、浅色和深色模式。
- 完全移除右下角悬浮启动器。
- 保持唯一且可访问的对话框入口，同步 `aria-haspopup` 和 `aria-expanded` 状态。
- SPA 跳转或 CPAMP DOM 刷新后会自动重新绑定宿主控件。
- 保留 v0.1.1 的已存配色及其他浏览器偏好。

通过 CPAMP 插件市场升级到 `0.1.2`，刷新面板一次，然后使用右上角操作区原有的“主题”按钮。
